## 1. How do NeuroBOLT, UnEBOLT, UniEFS and MARBLE turn EEG into regional BOLD?

### Takeaway

All four estimate a regional BOLD value from preceding EEG, but they differ in what they retain before making that estimate: NeuroBOLT compresses two feature streams into pooled vectors; UnEBOLT adds region-conditioned readouts; UniEFS retains tokens and uses an fMRI-pretrained decoder; MARBLE uses spectral tokens, temporal state-space processing and region-query attention. The verified name behind the user's “UniBOLT” is **UnEBOLT: A Unified Model for EEG-to-BOLD Translation and Functional Connectivity Reconstruction**, published at MIDL 2026, distinct from **UniEFS / Mind the State**, published at ICML 2026. [NeuroBOLT code](https://github.com/soupeeli/NeuroBOLT/blob/b51b966516a9b0c0a87e6ee6a7b997101a443394/models/model.py), [UnEBOLT proceedings](https://proceedings.mlr.press/v315/li26g.html), [UniEFS proceedings](https://proceedings.mlr.press/v306/li26gp.html), [MARBLE code](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/models/marble.py).

### Cited Findings

#### The task in ordinary language

An EEG channel records a mixture of electrical activity reaching one scalp electrode. BOLD is a slower blood-oxygenation signal; its delay and smoothing mean that the useful input is a history of EEG rather than an instantaneous voltage. A region of interest, or ROI, reduces a brain map to a regional signal. These models generally predict **one atlas-level frame at a time** and repeat that prediction along a recording; this is different from acquiring a measured MRI volume. [NeuroBOLT, §§3–4](https://arxiv.org/html/2410.05341v1), [UnEBOLT, §2.1](https://raw.githubusercontent.com/mlresearch/v315/main/assets/li26g/li26g.pdf).

For NeuroBOLT's usual input, 26 channels × 16 seconds × 200 samples/second gives a 26 × 3,200 array. Its temporal stream divides each channel into sixteen one-second pieces, giving **416 EEG patch tokens**, each represented by 200 learned numbers; a class token is added internally. A token is simply a small vector describing one input piece. Learned electrode and time embeddings tell the transformer which electrode and time position each piece came from. [Upstream model constructor and forward pass](https://github.com/soupeeli/NeuroBOLT/blob/b51b966516a9b0c0a87e6ee6a7b997101a443394/models/model.py).

Attention lets one token combine information from other tokens. Mean pooling then averages the resulting token vectors into one summary, sacrificing their separate identities at that output interface. A Fourier spectrum instead describes oscillation strength at different frequencies; short Fourier windows track changes more closely, while longer windows resolve frequencies more finely. NeuroBOLT processes both representations and adds their summaries before its prediction head. [Temporal pooling and fusion](https://github.com/soupeeli/NeuroBOLT/blob/b51b966516a9b0c0a87e6ee6a7b997101a443394/models/model.py), [spectral embedding and pooling](https://github.com/soupeeli/NeuroBOLT/blob/b51b966516a9b0c0a87e6ee6a7b997101a443394/models/model_multiscale.py).

**An accessible distinction between the decoders:** UnEBOLT asks, “Given this common EEG summary and this region's identity, what value should I predict?” MARBLE asks, “For this region, which retained EEG pieces should I read?” UniEFS asks, “Which structured fMRI state can the EEG support, using a decoder that has already learned fMRI patterns?” These are explanatory interpretations of the mechanisms above, not experimentally established explanations of why one model wins. [UnEBOLT model](https://github.com/neurdylab/UnEBOLT/blob/09a382897b85820854ddd4e47a1f851fa43d32d9/models/unebolt_model.py), [MARBLE model](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/models/marble.py), [UniEFS method overview](https://soupeeli.github.io/UniEFS/).

**A useful tensor trace for a slide:** with the released 16-second spectral configuration, NeuroBOLT projects each scale onto 32 positions per channel, yielding 26 × 32 = **832 spectral tokens**, then averages them to one vector. MARBLE likewise produces 832 channel–time tokens, but its 64 ROI queries yield 64 distinct vectors before the scalar prediction heads. These counts are derived from the inspected 3,200-sample/100-sample configuration, not additional empirical results; they distinguish the spectral stream from NeuroBOLT's 416 one-second temporal tokens. [NeuroBOLT spectral shapes](https://github.com/soupeeli/NeuroBOLT/blob/b51b966516a9b0c0a87e6ee6a7b997101a443394/models/model_multiscale.py), [MARBLE reshape and decoder](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/models/marble.py).

#### Delay/HRF handling, losses and pretraining

| Model | How delay is handled | Objective and initialization |
| --- | --- | --- |
| **NeuroBOLT** | Uses preceding EEG history to learn a delayed mapping. It does not contain an explicitly fitted physiological HRF convolution in its forward pass. | The original training recipe uses MSE regression; the temporal branch starts from LaBraM EEG pretraining. An EEG-pretrained encoder is not already a trained EEG-to-BOLD model. [Model](https://github.com/soupeeli/NeuroBOLT/blob/b51b966516a9b0c0a87e6ee6a7b997101a443394/models/model.py), [training entry point](https://github.com/soupeeli/NeuroBOLT/blob/b51b966516a9b0c0a87e6ee6a7b997101a443394/main.py). |
| **UnEBOLT** | The 16-second historical window supplies implicit lag information, rather than an explicit estimated HRF. | Published and command-line default loss: 0.8 MSE + 0.1 temporal-correlation loss + 0.1 spatial-correlation loss. Temporal correlation is over batch rows for each ROI; spatial correlation is across ROIs within a row. LaBraM initializes the temporal encoder. The loss class's standalone defaults differ from the main program's explicitly supplied weights; use main.py's actual call. [Loss implementation](https://github.com/neurdylab/UnEBOLT/blob/09a382897b85820854ddd4e47a1f851fa43d32d9/customized_losses.py), [main.py](https://github.com/neurdylab/UnEBOLT/blob/09a382897b85820854ddd4e47a1f851fa43d32d9/main.py). |
| **UniEFS** | Historical EEG plus an EEG-derived vigilance prompt shifted by five seconds to reflect BOLD delay. This is not an individually estimated HRF. | Stage 1 masked-ROI MSE pretrains on unpaired fMRI, then adapts on training-split paired-study fMRI. Stage 2 freezes the fMRI encoder/decoder and trains EEG mapping using latent MSE alignment plus reconstruction MSE/spatial correlation. The paper specifies λMSE = 0.5, λalign = 0.8 and λrecon = 0.2; its low-rank alignment is “LoRA-inspired,” not evidence that only LoRA parameters are trained. [Final paper, §2 and Appendix C](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26gp/li26gp.pdf). |
| **MARBLE** | Mamba supplies recurrent memory over the input sequence, described as an inductive bias for HRF-relevant temporal structure. It does not identify a physiological HRF. | Code uses the same 0.8 MSE / 0.1 temporal-correlation / 0.1 spatial-correlation combination. No pretrained encoder loading is evident in its model; the paper initializes its LaBraM-derived comparison models from LaBraM. [Loss code](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/utils.py), [training entry point](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/main.py), [paper, §3](https://papers.miccai.org/miccai-2026/paper/4437_paper.pdf). |

MSE penalizes wrong magnitudes; correlation losses reward matching relative variation. Temporal correlation compares a region over examples; spatial correlation compares the pattern across regions for an example. **Neither is the same as directly matching the whole functional-connectivity matrix.** UnEBOLT and MARBLE's inspected objectives contain no separate FC-matrix loss. [UnEBOLT loss](https://github.com/neurdylab/UnEBOLT/blob/09a382897b85820854ddd4e47a1f851fa43d32d9/customized_losses.py), [MARBLE loss/FC functions](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/utils.py).

### Inferences

- **Retaining tokens is a testable design choice, not a guarantee of information recovery.** An ROI query can use separate channel/time embeddings only if the encoder still provides useful separate features. It cannot restore measurements absent from EEG. This motivates testing the decoder separately from replacing the whole encoder. [NeuroBOLT pooling](https://github.com/soupeeli/NeuroBOLT/blob/b51b966516a9b0c0a87e6ee6a7b997101a443394/models/model.py), [MARBLE decoding](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/models/marble.py).
- **Mamba memory is not proof of haemodynamic identification or an online pipeline.** MARBLE's temporal scale projection already mixes positions within the historical window, and its later attention is not a time-causal mask. A prediction can use only a completed past window while still lacking a streaming state implementation; retrospective cleaning must also be audited. The authors explicitly softened the HRF interpretation in their response to reviewers. [Code](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/models/marble.py), [official reviews and author response](https://papers.miccai.org/miccai-2026/0612-Paper4437.html).
- **A region embedding is a learned address, not an anatomical measurement.** UnEBOLT's P-dimensional identity vectors and MARBLE's fixed ROI queries do not by themselves establish arbitrary-atlas or unseen-ROI generalization. Attention topographies should be checked by perturbation/ablation before interpreting them as physiological source maps. [UnEBOLT ROI table](https://github.com/neurdylab/UnEBOLT/blob/09a382897b85820854ddd4e47a1f851fa43d32d9/models/unebolt_model.py), [MARBLE queries](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/models/marble.py).

### Gaps

- UniEFS's exact token-axis mapping, handling of a previously unseen dataset token, and missing-context implementation cannot be verified without released code. Its paper's reconstruction equations describe signal MSE/spatial correlation, while a later ablation passage refers to an “MSE-based connectivity loss”; obtain the implemented loss before claiming a separate FC penalty. [Equations 3–4 and Appendix D.14](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26gp/li26gp.pdf).
- None of these architectural descriptions proves patient-specific HRF accuracy, real-time performance, or regional physiological specificity. Those require an appropriately defined experiment.

## 3. Which modifications address observed failures, and what can be completed in two weeks?

### Takeaway

Three useful directions are **retain tokens for ROI-specific pooling**, **represent EEG history with a compact lag/memory model**, and **separate shared global prediction from regional residual prediction while checking magnitude error**. For two weeks, choose the first as the single architecture experiment; keep the other two as evidence-backed next questions, with the existing ridge and global-template controls defining what counts as progress.

### Inferences

#### Candidate 1 — Preserve spectral tokens and let each ROI pool its own evidence

**Proposed change:** expose the spectral encoder's token sequence immediately before its existing mean reduction; add a small learned ROI-query cross-attention readout and regional linear heads. Initially retain the spectral backbone, scales, input duration and MSE objective. Compare with its ordinary shared linear readout. This borrows MARBLE's decoder mechanism while testing the pooling bottleneck identified in local NeuroBOLT ablations. A later temporal-branch version is a separate question. [Existing spectral pooling site](https://github.com/soupeeli/NeuroBOLT/blob/b51b966516a9b0c0a87e6ee6a7b997101a443394/models/model_multiscale.py), [MARBLE decoder](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/models/marble.py), [local branch findings](<C:/Users/Seamus/Documents/GitHub/NeuroBOLT/reports/NeuroBOLT hypothesis tests.md>).

**Explicit hypothesis H1:** region-specific attention over retained tokens improves regional error or regional contrasts above shared pooling, without simply making all regions track the same global signal. **Falsifier:** no reliable improvement over the pooled model/global-template control, or apparent gains disappear against a pooled nonlinear head with a similar parameter budget. That parameter-control comparison distinguishes extra capacity from preserving token-level access; inspect attention alongside channel/time perturbations, not as proof of source localisation. [Mechanism](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/models/marble.py), [local connectivity failure](<C:/Users/Seamus/Documents/GitHub/NeuroBOLT/reports/NeuroBOLT hypothesis tests.md>).

**Contribution status:** an incremental architectural adaptation, since learned ROI-query decoding already exists in MARBLE. A carefully controlled test of whether that mechanism corrects this specific failure is a legitimate research result; it is not a claim to have invented ROI attention. A distinctive new method would require a further formulation and literature comparison. [Published MARBLE contribution](https://papers.miccai.org/miccai-2026/0612-Paper4437.html).

#### Candidate 2 — Add compact lag structure instead of extending the pretrained grid

**Proposed change:** keep a 16- or 24-second spectral front end, then represent the relevant 24–32-second history through a small causal lag-basis convolution or recurrent state module. The beginner version is a regularized learned convolution over chronological band-power bins; compare it against ridge on exactly those bins before considering a Mamba replacement. This tests structured memory rather than a large model transplant. [Local history comparisons](<C:/Users/Seamus/Documents/GitHub/NeuroBOLT/reports/NeuroBOLT hypothesis tests.md>), [MARBLE temporal mechanism](https://github.com/emeelkaa/marble/blob/28ae2ab16585f7a0cd57fcc961952661cce3e1d6/models/marble.py).

**Explicit hypothesis H2:** a compact chronological representation uses older EEG more effectively than lengthening NeuroBOLT's positional grid, improving held-out error at matched feature access and reasonable compute. **Falsifier:** it fails to beat lagged ridge, or any advantage disappears when ridge and the neural model receive identical history. Calling the learned kernel an HRF would require additional identification evidence; a useful predictive lag filter alone is sufficient for this experiment. [Original stopped/completed history arms](<C:/Users/Seamus/Documents/GitHub/NeuroBOLT/reports/NeuroBOLT hypothesis tests.md>), [authors' qualified HRF interpretation](https://papers.miccai.org/miccai-2026/0612-Paper4437.html).

**Contribution status:** lagged linear models, convolutions and state-space models are established ideas. Replacing attention with Mamba is incremental adaptation. A constrained regional lag model could become a more original direction only if its constraints are motivated, distinguished from existing methods and supported by results; that is beyond a guaranteed two-week contribution. [UnEBOLT history formulation](https://raw.githubusercontent.com/mlresearch/v315/main/assets/li26g/li26g.pdf), [MARBLE](https://papers.miccai.org/miccai-2026/paper/4437_paper.pdf).

#### Candidate 3 — Separate shared global prediction from regional residuals

**Proposed change:** predict an EEG-derived global component and add ROI-specific residuals: predicted ROI = training-derived regional loading × predicted global + predicted regional residual. Compare with the global-only template and with a direct multi-output head. Use magnitude-sensitive MSE as the initial objective; only then ablate a small spatial-correlation term borrowed from UnEBOLT/UniEFS. Count validation-fitted output recalibration separately. Measured test global BOLD is never an input. [Existing global-template control](<C:/Users/Seamus/Documents/GitHub/NeuroBOLT/research_notes/Clinical EEG fMRI thesis exploration/M3 experiments.md>), [UnEBOLT loss](https://github.com/neurdylab/UnEBOLT/blob/09a382897b85820854ddd4e47a1f851fa43d32d9/customized_losses.py), [UniEFS reconstruction objective](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26gp/li26gp.pdf).

**Explicit hypothesis H3:** an explicit shared/residual split reduces output collapse and learns regional information beyond the global template. **Falsifier:** residual/contrast predictive R² remains non-positive or improvements occur only in raw correlation/FC resemblance. Report prediction/target SD ratio and error as well as r; simply rescaling a weak prediction to match the target's SD can worsen MSE and is not automatically a solution. [Existing magnitude and residual failures](<C:/Users/Seamus/Documents/GitHub/NeuroBOLT/reports/Clinical EEG fMRI thesis exploration.md>).

**Contribution status:** residualization, multi-task heads and correlation losses are established. The research question is whether their controlled combination recovers reproducible region-specific signal in this setting. An unsuccessful result that rules out this proposed explanation is useful; it does not establish a biological ceiling. [Local template/residual protocol and limitations](<C:/Users/Seamus/Documents/GitHub/NeuroBOLT/research_notes/Clinical EEG fMRI thesis exploration/M3 experiments.md>).
